# 世界同步装置 (lh-world-sync)

将一个世界保存为「主世界基准快照」，其它世界一键恢复为它的样子——**设置 + 模组启用状态一起同步**。
适用于「主世界配好一套环境，之后每开一个新团世界都要重新配一遍」的场景。

- 兼容 Foundry VTT **v13**（最低 13.351），系统 **dnd5e 5.3.3**
- 仅 GM 可用；玩家端不加载任何界面
- MIT 授权，可自由分发与修改

## 安装

**方式一（推荐，可检测更新）**：Foundry 设置 →「模组」→「安装模组」→ 在底部粘贴以下地址：

```
https://raw.githubusercontent.com/Ryuka16/lh-world-sync/main/module.json
```

**方式二（手动）**：从 [Releases](https://github.com/Ryuka16/lh-world-sync/releases) 下载 `lh-world-sync.zip`，解压出的 `lh-world-sync` 文件夹放入 `Data/modules/`，重启 Foundry 后在模组管理中启用。

安装后在控制台输入 `window.__WSYNC_VER` 可确认加载的版本号。

## 功能

| 功能 | 说明 |
|---|---|
| 存主世界 | 将当前世界的全部 **world 级设置**（系统 dnd5e.* 与各模块设置）保存为快照，存于模块 `storage/` 目录，服务器上所有世界共享读取 |
| 恢复主世界 | 将当前世界恢复为基准快照的状态：设置与**模组启用状态**一并恢复，完成后页面自动刷新 |
| 自动提醒 | GM 进入世界时若发现有差异，自动弹窗询问：**恢复主世界 / 暂不恢复 / 不再自动提醒**（可随时改回） |
| 查看差异 | 恢复前列出差异清单：每一项显示「当前值 → 基准值」，并标注 **→开启 / →关闭 / →修改** |
| 回档 | 每次恢复前自动记账，回档＝按账本精确还原上一次恢复改动的设置；此后手动调整的其他设置不受影响。**回档记录按世界分开保存**，多个世界各留各的，不会互相覆盖 |
| 快照文件 | 快照可**导出下载 / 复制全文 / 从文件导入 / 粘贴导入**，用于跨服务器迁移 |
| 恢复范围 | 在「高级选项」中可按模块勾选恢复范围（默认全部恢复），配置一次即可 |
| 主题 | 深空蓝 / 蓝白 / 琉璃绿 / 鎏金 / 薄荷 五种配色，每位用户可自行选择（client 级设置） |

## 入口

- 右侧边栏「设置」齿轮旁的「同步」按钮
- 设置 → 模组设置 → 世界同步装置 → 「世界同步装置面板」
- 控制台：`window.lhWorldSync.openPanel()`

## 典型用法

1. 在一个配置齐全的世界（基准团）中打开面板，点击 **存主世界**
2. 进入任意其它世界 → 启用本模块 → GM 进入时会弹窗提示差异 → 点击 **恢复主世界** → 页面自动刷新，设置与模组启用状态全部到位
3. 若结果不符合预期 → 在面板中点击 **回档**，还原到恢复前的状态并查看清单
4. 跨服务器迁移 → 在「高级选项 → 快照文件」中导出快照文件，在目标服务器导入

> 面板默认只显示「存主世界 / 恢复主世界 / 回档」三个按钮与一行状态；恢复范围细调、快照文件、自动提醒开关均收在「高级选项」折叠区中。

## 快照格式 (schema 1)

```json
{
  "schema": 1,
  "app": "lh-world-sync",
  "appVersion": "1.0.9",
  "sourceWorld": "主世界名",
  "savedAt": "ISO 时间",
  "systemId": "dnd5e",
  "systemVersion": "5.3.3",
  "coreVersion": "13.351",
  "modules": { "midi-qol": "13.0.55", "...": "..." },
  "settings": [ { "key": "dnd5e.largerTokenArms", "value": true }, "..." ]
}
```

## 回档账本格式 (schema 2)

回档记录与快照同目录，存在 `apply-log.json` 中，**按世界分区**——多个世界各留各的，互不覆盖：

```json
{
  "schema": 2,
  "worlds": {
    "<worldId>": {
      "ts": "ISO 时间",
      "worldId": "<worldId>",
      "worldTitle": "世界显示名",
      "appVersion": "1.0.9",
      "prev": { "<设置键>": { "present": true, "value": "…恢复前的值…" } }
    }
  }
}
```

- `worldId` 取 `game.world.id`，世界改名不影响归属
- `prev` 只记录「上一次恢复实际改动过的键」；`present: false` 表示该键当时并不存在（回档时把它删掉）
- 回档只认当前世界的那一格：读不到就提示「暂无可回档记录」，**绝不会拿别的世界的旧值回填**
- 旧版账本（无世界分区的单条格式）不再作为回档依据——宁可少一次回档，也不乱写

## 边界与安全（设计决策）

- **同步范围为 world 级设置**；client 级设置（浏览器本地偏好）不在同步范围内。玩家账号无需同步——同一服务器的所有世界共享用户列表。
- **默认排除** `core.time`（世界时间）、`core.permissions`（权限，GM 专用）与 `foundry-mcp-bridge.lastActivity`（该模组的心跳时间戳，每次刷新都会变化，同步无意义且会造成误报差异）；面板「高级选项」中可追加排除项。
- **模组启用状态**（`core.moduleConfiguration`）默认包含在恢复范围内：此前被关闭的模组会随主世界重新启用。恢复后页面自动刷新，无需手动操作。
- **恢复前先记账、失败自动回滚**：批量写入失败时会按账本还原，不会写入一半。
- **恢复完成后 3 秒自动刷新页面**（模组启用状态需刷新页面才生效）。如需撤销，刷新完成后点击「回档」即可。
- **Foundry 未提供游戏内文件删除 API**：快照与账本均为固定文件名覆盖写入（`world-snapshot-master.json` / `apply-log.json`），不会累积文件；账本自 v1.0.9 起按世界分区存放在同一个文件里（旧版的单条账本会被忽略，不再用于回档）。如需清空，可在服务器 `Data/modules/lh-world-sync/storage/` 中手动删除。
